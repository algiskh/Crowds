# Задачи

Планы работ, которые идут дольше одной сессии. Один файл — одна задача: `T-NNN.md`.

- Статусы: `открыта` → `в работе` → `ждёт проверки` → `закрыта` (закрывает только пользователь).
- Разделы: «Цель», «Порядок» (чек-лист `- [ ]`), «Решения» (нумерованные, с датой), «Открытые вопросы»,
  «Что проверить» (шаги для Play mode).
- Пункт, код которого написан, но не проверен в Unity, остаётся `- [ ]` с пометкой «(код готов, ждёт проверки в Unity)».
